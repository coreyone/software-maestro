# Rule: Jake Knapp Design Sprint — Diverge & Sketch (Tuesday)

> [!IMPORTANT]
> **Foundation**: Grounded in **Jake Knapp & John Zeratsky** (*Sprint*).
> **The Prime Directive**: *"Work alone together."* Eliminate group brainstorming. Diverge independently through 4-step sketching, Crazy 8s fast iteration, and self-explanatory 3-panel Solution Sketches with 100% real copy.
>
> **Lifecycle Governance**:
> - **Input**: Consumes the locked target from [`/design-sprint-map`](../design-sprint-map/SKILL.md).
> - **Output Handoff**: Delivers anonymous 3-panel Solution Sketches to [`/design-storyboard-decide`](../design-storyboard-decide/SKILL.md).

---

## When to use

Use this skill on Tuesday of a Design Sprint to generate competing solutions:
- Conducting **Lightning Demos** (3-minute analog product inspirations).
- Executing the **4-Step Sketch Method**:
  1. *Notes* (20 min cognitive review).
  2. *Ideas* (20 min private doodling/mapping).
  3. *Crazy 8s* (8 distinct visual variations in 8 minutes / 60s per frame).
  4. *3-Panel Solution Sketch* (30–45 min detailed narrative storyboard).
- Producing **self-explanatory, anonymous sketches** with real headlines, real microcopy, and catchy titles.

## When not to use

Do not use this skill for:
- Monday target mapping (use `design-sprint-map`).
- Group critique, heatmap dot voting, or Decider supervotes (use `design-storyboard-decide`).
- Building interactive prototypes in code (use `design-rapid-prototype-facade`).

## Trigger cues

- Request mentions: `crazy 8s`, `solution sketch`, `divergent UI sketching`, `sketch phase`, `work alone together`, `competing UI concepts`, `4 step sketch`, `lightning demos`, `tuesday sprint sketch`.

## Inputs required

1. **Locked Sprint Target & Questions**: From `design-sprint-map`.
2. **Lightning Demo Inspiration**: Analog products and compelling UI patterns.
3. **Source of truth**: [references/source.md](references/source.md)

## Instructions

1. Read [references/source.md](references/source.md) first.
2. **Conduct Lightning Demos**:
   - Capture 3-5 external inspiring mechanisms on the board.
3. **Execute the 4-Step Sketch**:
   - *Step 1 (Notes)*: Review target, HMWs, and goals.
   - *Step 2 (Ideas)*: Doodle layouts and user flows privately.
   - *Step 3 (Crazy 8s)*: Fold sheet into 8 frames. Force 8 distinct visual variations in 8 minutes.
   - *Step 4 (3-Panel Solution Sketch)*: Create an anonymous 3-panel comic (Panel 1: Entry, Panel 2: Core Mechanism, Panel 3: Value Payoff).
4. **Enforce Realistic Microcopy**:
   - Strict ban on *Lorem Ipsum* or placeholder text. Write actual copy, numbers, and labels.
   - Give each sketch a memorable 2-3 word title.

## Completion gate

- [ ] Crazy 8s matrix with 8 distinct variations documented.
- [ ] 3-Panel Solution Sketches produced with Panel 1 (Entry), Panel 2 (Action), Panel 3 (Payoff).
- [ ] 100% authentic copy with zero placeholder text.
- [ ] Distinct memorable titles attached.
