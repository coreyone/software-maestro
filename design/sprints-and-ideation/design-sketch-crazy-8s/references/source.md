# Jake Knapp Design Sprint: Diverge & Sketch (Tuesday)

## 1. First Principles & Mindsets
- **Work Alone Together**: Group brainstorming generates groupthink; silent independent sketching generates true divergence.
- **Remix & Improve**: Great solutions combine existing proven patterns from adjacent industries.
- **Self-Explanatory Axiom**: If a sketch needs a presentation pitch, it is poorly designed.
- **Words Matter**: Microcopy carries the value proposition; zero Lorem Ipsum permitted.

## 2. The 4-Step Sketch Protocol
1. **Notes (20m)**: Gather data from sprint map, questions, and lightning demos.
2. **Ideas (20m)**: Private mind-mapping and rough layout doodling.
3. **Crazy 8s (8m)**: 8 distinct variations in 8 minutes (60 seconds per frame).
4. **3-Panel Solution Sketch (45m)**: Entry $\rightarrow$ Core Mechanism $\rightarrow$ Payoff.
