# Rule: Technical Language & Documentation Standard (ASD-STE100 + Google DevDocs)

## When to use
Use when authoring documentation, PR summaries, code comments, architecture decision records, or commit messages.

## Non-Negotiable Rules
1. **Sentence Length**: $\le 20$ words for procedural/instructions; $\le 25$ words for descriptive text.
2. **Noun Stacks**: Maximum 3 consecutive nouns.
3. **Unambiguous Connectors**: Use `because` (not `since`/`as`), `after` (not `once`), `can`/`must` (not `may`).
4. **Imperative Commits**: Conventional commits with imperative verbs (`feat: add auth token refresh`).

## Anti-AI Slop & Voice Invariants

Cut the AI garbage but keep my voice, jokes, cadence, bluntness, and rhythm. Edit minimally. Never sanitize, homogenize, or invent facts, quotes, or stats; ask if unclear. Active voice with human subjects. Direct verbs; use is and has over serves as. Specific names, dates, metrics, and mechanisms only. If a sentence fits anywhere else, cut it. Show facts; delete commentary declaring things important, obvious, or subtle. Repeat the right word instead of cycling synonyms. Ban binary contrasts (not X but Y), negative lists, throat-clearing intros, fake insights (what nobody tells you, part everyone misses), colon reveals, and trailing participle clauses (highlighting, underscoring). Kill puffery (pivotal moment, testament to), reader coaching (in other words, that matters because), and weasel sourcing (studies show, experts agree). No dramatic fragments (that is it), staccato cadences, fake-profound mic drops, or recap conclusions (in conclusion, ultimately). End on the last concrete fact or next step. No em dashes in short copy, max two in long drafts. No header emojis, decorative bolding, pointless bullets, or micro-headers. Ban outright: delve, foster, leverage, utilize, facilitate, empower, streamline, robust, cutting-edge, paradigm shift, game changer, this is huge, this changes everything, tapestry, realm, beacon, multifaceted, meticulous, intricate, paramount, transformative, elevate, embark, supercharge, harness, ever-evolving. Drop filler adverbs (literally, actually, fundamentally, crucially) and dead phrases (at the end of the day, it is worth noting, in today's world, going forward, let us dive in).
