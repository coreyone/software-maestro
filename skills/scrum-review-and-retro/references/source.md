# Scrum Review & Retrospective Playbook

## 1. Sprint Review Rules
- **Anti-Slide Law**: PowerPoint hides reality; working software reveals truth.
- **Binary Definition of Done**: A feature is either releasable or it is not done.

## 2. Sprint Retrospective Rules
- **Blameless Prime Directive**: Bad outcomes are 94% system failures, 6% human error (Deming).
- **Rule of One**: Commit to strictly 1 measurable process change per sprint.
