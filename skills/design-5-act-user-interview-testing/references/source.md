# Michael Margolis & Jake Knapp: 5-Act User Interview Testing (Friday)

## 1. First Principles & Mindsets
- **Jakob Nielsen 5-User Rule**: 5 users uncover $\sim 85\%$ of usability and concept flaws.
- **The 5-Act Interview**: Michael Margolis protocol structured to eliminate interviewer confirmation bias.
- **Neutral Probing**: Never defend the prototype, explain features, or ask leading questions.
- **Pattern Scorecard**: Scan columns vertically on the matrix to detect high-confidence green vs red patterns.

## 2. The 5-Act Interview Script Matrix
1. **Act 1: Friendly Welcome (5m)**: Lower defenses; test the prototype, not the user.
2. **Act 2: Context Questions (15m)**: Probe current habits and workflows.
3. **Act 3: Introduce Prototype (5m)**: Set opening scenario.
4. **Act 4: Tasks & Nudges (30m)**: Think-aloud observations; neutral prompts.
5. **Act 5: Quick Debrief (5m)**: Holistic value, pricing, and alternative comparison.
