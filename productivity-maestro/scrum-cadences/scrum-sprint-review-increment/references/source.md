# Scrum Sprint Review: Working Increment Inspection

## 1. First Principles & Psychological Antidotes
- **Anti-Slide Law**: PowerPoint hides reality; working software reveals truth.
- **Binary Definition of Done**: A feature is either releasable or it is not done. There is no 90% done in Scrum.
- **Backlog Adaptation**: The review is a working session to steer future investment, not an acceptance sign-off ritual.

## 2. Review Protocol
1. Product Owner summarizes what was done and what was not done.
2. Developers demonstrate working software.
3. Stakeholders provide feedback; Product Backlog is adapted.
